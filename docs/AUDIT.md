## 硬风控规则（引擎内写死，AI 无权修改）

```text
1. 现货只做多，杠杆恒为 1
2. 单笔 ≤ 100 USDT；日累计 ≤ 300 USDT
3. 总敞口 ≤ 权益 25–50%；BTC+ETH 视为同一风险簇
4. 每笔必须有交易所侧止损单，无止损 = 拒绝开仓
5. 数据 stale（超阈值）→ 拒绝一切下单
6. 日内亏损 ≥ 3% → 当日停止开仓
7. 连续 3 笔止损 → 冷却 24h
8. KILL 开关存在 → 立即停止开新仓
9. 下单前必须通过金丝雀限额与标的白名单
10. 无成交确认 = 视为未持仓，绝不假设已建仓
```

## 为什么 AI 不进执行环

| 我做不到 | 原因 |
|---|---|
| 毫秒/秒级盯盘与止损 | 模型是回合制的：只有收到消息或定时任务触发时才运行 |
| 7×24 不中断 | DSH 崩溃、断网、模型不可用 → 无人平仓 |
| 输出确定性 | 同一输入可能给出不同结论，真钱不能建立在采样上 |
| 自证「已止损」 | 只有交易所回执才算数 |

因此：**引擎掌盘（快、确定、可审计），AI 掌舵（研究、参数、复盘）**。
AI 只写配置，配置有硬边界（`PARAM_BOUNDS` / `MOMENTUM_BOUNDS`），越界直接拒绝。

研究用途，不构成投资建议。
